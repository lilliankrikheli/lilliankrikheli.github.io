# Dr Lillian Krikheli — academic website

A responsive, dependency-free website for GitHub Pages. All content and styling are in `index.html`; no build tools or JavaScript are required.

## Update content
1. Open `index.html` in GitHub and choose the pencil (Edit).
2. Find the relevant section using its comment or section ID: about, research, resources, presentations.
3. Edit the text while preserving surrounding HTML tags. Use `&amp;` for ampersands.
4. Commit the changes to `main`. GitHub Pages republishes automatically.

To add a publication, copy an existing `<article class="publication">…</article>` block and replace the title, authors, journal, year and links with verified details. Do not use incomplete or guessed citations.

Repository: `lilliankrikheli/lilliankrikheli.github.io`.
In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`, then Save.
Expected address: https://lilliankrikheli.github.io/
Only call this published after Pages confirms deployment and the address loads.

## Structure
Four sections: About, Research (including two recent selected works), Resources, and Talks & Conversations. Contact is a simple email link.

## Sources
Public university, ORCID, PubMed and resource links are included directly in the page. Content checked 25 October 2026. No publication metrics or unsupported claims have been added.

## Design and accessibility
Light grey background with restrained purple accents, responsive layouts, semantic headings, keyboard focus states, skip link, reduced-motion support and print styles. DM Sans is loaded from Google Fonts. There are no packages or tracking scripts.
